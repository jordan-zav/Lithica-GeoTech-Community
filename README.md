# Lithica GeoTech Community

Edición comunitaria de consulta y cálculo geotécnico de Lithica. Contiene una aplicación Flutter para Android y Windows con base de materiales, clasificaciones RMR y Q-System, criterio Hoek-Brown y referencias ISRM.

Este repositorio es independiente de Lithica-GeoTech, la edición propietaria. Las funciones nuevas, los resultados de pruebas y los binarios de esa edición no acreditan el estado de Community. La versión de pubspec.yaml identifica la fuente y no una publicación confirmada en Play.

## Desarrollo

Conservar el checkout y los scripts en E:. Reutilizar Flutter, Android SDK y cachés desde D:\DevResources\Shared; preparar el entorno de la sesión y el bloqueo del workspace antes de comandos directos. Este repositorio no incorpora el supervisor .build-support ni el panel administrativo privado. No importar credenciales o scripts privados para simular esa integración.

Revisar parámetros, unidades y versión del método antes de usar los resultados geotécnicos. Las propiedades de referencia no sustituyen mediciones del proyecto.
